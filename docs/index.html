The problem: three incompatible schemas

A PreToolUse hook that works in Claude Code will not work in Cursor or Codex without translation. The config paths, event names, and block mechanisms are all different.

How it works

01

Write a policy

One YAML file describes every guardrail. No JavaScript, no TypeScript, no per-harness config.

02

Compile

One command translates the policy to the correct native format for each harness. Guard scripts are generated in .hooksmith/.

03

Run

The hooks fire natively. No runtime bridge, no daemon, no network calls.

# hooksmith.yaml
policies:
  - name: block-destructive-shell
    match: Bash
    block_if: command =~ /rm\\s+-rf|git\\s+reset\\s+--hard/
    decision: deny
    reason: "Destructive command blocked by hooksmith"

# Compile to every harness
python scripts/compile.py --project /path/to/project --harness all
